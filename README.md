REQUIREMENTS

1. Ролі користувачів (Actors)
Хто користується системою і які у них права:
Admin (Дід): Має повний доступ до системи (CRUD для всіх сутностей). Може змінювати константи (ціни, зарплати). Бачить фінансові звіти та загальний профіт. Роздає знижки (кумівство).
Manager: Має права адміністратора для операційної роботи (реєстрація дітей, створення груп), але отримує фіксовану зарплату. 
Parent (Батьки): Бачать розклад лише своєї дитини/групи. Бачать фінальну вартість навчання(за місяць та за рік), дату до якої діє оплата навчання та харчування для своєї дитини. Можуть додавати інформацію про дитину (наприклад, "не любить гречку"). Не бачать чужих знижок та даних тільки свою дитину.
Teacher/Tutor (Вихователі та викладачі гуртків): Бачать розклад лише для своїх груп/занять.

2. Сутності (Entities)
Головні об'єкти, якими буде оперувати база даних:
Child (Дитина): Вік (2-5 років), інформацію від батьків (вподобання/алергії), прив'язка до батьків та групи, також потрібно зберегти інформацію про наявність родичів депутатів, про наявність пільги (10%, 20%, 30%), дату заверщення оплати навчання (yy/mm/dd), та статус навчання (активний /не активний).
Parent (Батьки): ПІБ, контакти. Можуть мати кількох дітей у садку та борг.
Group (Група): Має прикріплену кімнату. Діти лише одного віку. Максимум 20 дітей в групі. Та максимум 30 груп. 
Employees (Викладач): Вихователі, Помічники вихователя, Викладачі гуртків, Менеджер. Мають зп, посаду, та статус працевлаштування (активний /не активний). Вихователі та помічники прив'язані до однієї групи. 

3. Бізнес-правила (Business Rules)
Оплата персоналу: Вихователі (1 на групу 2к за дитину ЗП доплата після 12 в групі +3к), Помічники вихователя (1 на групу 20к ЗП доплата після 12 в групі +3к), Викладачі гуртків (40к), Менеджер (80к).
Базова вартість кімнати (за замовчуванням 50к/міс) всього 20 кімнат за замовчуванням але можна добудувати.
Формування груп: Діти різного віку не можуть бути в одній групі. Максимальна кількість дітей — 20.
Оплата за навчання: Базова ціна — 15 000 грн/місяць.
Оплата на рік вперед дає знижку 12% (не діє на харчування)
Оплата за харчування: Для 2-річних — 300 грн/день. За кожен наступний рік життя +100 грн/день. Пільги на харчування не діють. 
Система знижок (пільг): Фіксовані рівні знижок на навчання: 10%, 20%, 30%. Призначаються Адміном вручну.
Викладачі проводять заняття тільки для ожної групи в один момент. 
Розклад: Дитина в садку 8 годин. З них: 1 година сну, 3 прийоми їжі по 30 хв (не підряд) година прогулянка на вулиці, півтора години вільний час (між активностями), та 3 заняття. Кількість занять для дітей одного віку має бути однаковою.

4. Функціонал системи
Базовий CRUD (Створення, Читання, Оновлення, Видалення): Управління дітьми, батьками, групами, персоналом, розкладом, цінами.
Генерація розкладу: Автоматичне створення чорнового рівномірного розкладу(щоб 2 групи не були в одному кабінеті англійської) з можливістю ручного редагування адміном. По 3 заняття на день для дітей, одне й те саме заняття не має убти двічі в один день та заняття мають бути в рівній кількості на протязі тижня (по 3 на тиждень(3 пари на день * 5 днів в тижні = 15/5 предметів = 3))
Розрахунок вартості для батьків (Billing): Ендпоінт, який повертає суму до оплати за місяць/рік для конкретної дитини з урахуванням її знижок, віку (ціна їжі) та типу оплати.
Релазувати автентифікацію користувачів використовуючи JWT (термін життя токена 30 хв).
Економічні розрахунки для Адміна:
Ендпоінт розрахунку профіту по конкретній групі.
Ендпоінт розрахунку загального профіту садка.
Ендпоінт оптимізації/прогнозування: введення бажаної кількості дітей (наприклад, 150) для розрахунку необхідної кількості кімнат, вихователів та очікуваного прибутку.
